# AI PLAYGROUND — אוהל בנים שילה, כיתה ז׳

תערוכת עבודות בינה מלאכותית שנוצרו בידי התלמידים.

## פרסום

אתר סטטי ללא שרת. העלו את כל תוכן התיקייה לשורש מאגר GitHub. ב־Vercel בחרו `Other` כ־Framework Preset, והשאירו Build Command ריק ו־Output Directory כ־`.`.

## הוספת עבודות

1. שמרו קובץ HTML חדש בתיקייה `projects/` בשם באנגלית.
2. הוסיפו רשומה למערך `window.SHOWCASE_PROJECTS` בקובץ `projects.js` עם `id`, `student`, `title`, `description`, `category`, `emoji`, `color`, `url`.
3. האתר מעדכן אוטומטית את המספר ואת הכרטיסים.

## הערות

- חלק מעבודות התלמידים נשענות על ספריות חיצוניות מהרשת; יש צורך בחיבור אינטרנט.
- HoloFocus הומר מ־TSX ל־JavaScript לשימוש בדפדפן ומסתמך על React ו־lucide-react דרך CDN.
- כדאי לוודא אישור בית הספר לפרסום שמות מלאים של קטינים וקישורים חיצוניים.
